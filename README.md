# Sistema de Gestão para Escola de Idiomas 🏫🌐

Este é o **principal e mais robusto projeto** desenvolvido por mim utilizando C# e Windows Forms, integrado a um banco de dados relacional MySQL. A aplicação foi projetada para simular o ecossistema real de uma instituição de ensino, gerenciando fluxos de dados complexos através de uma interface gráfica (GUI) altamente otimizada, moderna e intuitiva.

O grande diferencial deste projeto está na **arquitetura multi-tabelas**, exigindo uma modelagem de banco de dados avançada e a sincronização de múltiplos formulários e componentes visuais.

---

## 🎨 Destaques do Projeto & Layout Insano
- **UI/UX Otimizada:** Interface gráfica com design moderno, menus fluidos e componentes customizados para entregar uma experiência de uso profissional e limpa.
- **Arquitetura Multi-Tabelas:** Modelagem e manipulação de múltiplos cenários interligados (ex: Alunos, Turmas, Cursos, Matrículas e Professores) utilizando relacionamentos e chaves estrangeiras (FK).
- **CRUD Avançado Dinâmico:** Telas dedicadas para o gerenciamento completo de dados, onde as atualizações, consultas e exclusões refletem instantaneamente em todas as tabelas relacionadas do sistema.

## 🛠️ Stack Tecnológica & Infraestrutura
- **Linguagem de Programação:** C# (.NET)
- **Construção de Interface:** Windows Forms Application (Rich UI Components)
- **Persistência de Dados:** MySQL Server (Modelagem Relacional de Alto Impacto)
- **IDE de Desenvolvimento:** Microsoft Visual Studio

---

## 📈 Competências de Engenharia e Aprendizados Práticos
Sendo o ápice dos meus projetos em C# até o momento, o desenvolvimento do Sistema de Escola de Idiomas consolidou competências essenciais de nível de mercado:
1. **Modelagem de Dados e Integridade Referencial:** Criação de queries complexas envolvendo `JOINs` para unificar informações de tabelas distintas sem perder a performance.
2. **Navegação e Transmissão de Estado entre Telas:** Gerenciamento de eventos para abertura de múltiplos formulários, passando parâmetros e ID de registros de uma tela para outra de forma segura.
3. **Tratamento de Exceções e Regras de Negócio:** Implementação de validações robustas em código para impedir ações inválidas (ex: matricular um aluno em uma turma inexistente ou duplicar registros).
